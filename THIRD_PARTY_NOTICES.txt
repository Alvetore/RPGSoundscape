The Android APK bundles the same React frontend and serves it from a loopback
HTTP server on the device. Library transfers use the local Wi-Fi network only;
the QR code contains the PC address and access token, not the audio files.

- cobalt API fallback — public community instances. The application only sends the public
  video URL to the fallback instance; no cookies or local library data are sent.
